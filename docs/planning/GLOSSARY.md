# Glossary

One canonical term per concept. Synonyms to stop using follow `_Avoid:_`. Specs and code names follow this table
(REVIEW-CHECKLIST); a rename here is a rename in the specs in the same change. Case styles per layer (config keys,
enums, events, commands, ids, branches) are in [NAMING-CONVENTIONS.md](NAMING-CONVENTIONS.md), which also lists the
terms still waiting for an owner ruling.

## Players, sides and roles

| Term | Meaning |
|---|---|
| Commander | A persistent player profile (`commander_id`), possibly linked to several platform identities. On stream the player is an **Operator** (lore table) |
| Callsign | Public name on stream. Generated by default (e.g. `VIPER-27`); a custom one unlocks after the operator's first completed mission and passes moderation (Q-PROG-3) |
| Tombstone callsign | The callsign a deleted commander keeps: shown as `REDACTED-` plus a random 4-character tag stored at deletion (e.g. `REDACTED-7KQ2`), so distinct deleted players stay distinct in replays (DATA-MODEL §4.2, Q-ALN-29) |
| Coalition | The players' side, plus the friendly AI garrison. Shown on stream as **the Quorum** (Q-BRAND-7). _Avoid:_ Clearwave (retired 2026-10-18) |
| Enemy | The AI side, run by the Threat Director. Shown on stream as **the Static** |
| AI garrison | Friendly AI units of the coalition. They take Tasking Board jobs no human has claimed and never start offense; the one exception is a counterattack on a node just lost (GAMEPLAY §1b, Q-GD-31) |
| Threat Director | The rules engine that runs the enemy: tiers, budget, threat memory and operations. It creates jobs on the enemy's Tasking Board and never moves units directly (THREAT-DIRECTOR, Q-GD-34) |
| Mastermind | The Static's taunting leader, the voice of its broadcasts. Quorum intel calls it **NULL**; the name it signs its own broadcasts with is TBD (Q-BRAND-4) |
| Lieutenant | A Static sub-commander that runs one sector or operation: a Threat Director profile with its own priorities, aggression, preferred operations and taunt voice, on the same mechanics (P4, Q-GD-38, NX-317). Shown as UNIDENTIFIED until intel reveals it |
| Game Master (GM) | A human with the `GAME_MASTER` role who, during play, drives only the Static and world events and injects jobs only into the Static's Tasking Board. Never sets objectives or campaign options (ADMIN-RBAC, Q-AI-8, Q-ALN-10, Q-ALN-11) |
| Command Center | The private admin console (moderation, users, AI/GM, campaign planning, rules, content); tailnet + Discord only (Q-ARCH-7, ADMIN-RBAC). Specs still also say "admin console" for it |
| Staff | The people who run the game from the Command Center: the owner, admins, moderators and Game Masters. Never players (Q-ALN-40). _Avoid:_ operator, which means a player only |
| Public site | The public app for replays, leaderboards, stats and the Field Manual; no admin features (Q-ARCH-7). _Avoid:_ companion site |
| Viewer simulator | Scripted bot operators that inject commands straight into the internal command queue for testing; never on the public channel and never through real chat accounts (Q-PROD-4, Q-LEGAL-7) |

## Units, jobs and the map

| Term | Meaning |
|---|---|
| Node | A named strategic location (airbase, FOB, port, factory, radar, bridge, HQ, sanctuary) |
| Stock | The supply held at a node |
| Theater | One campaign's map. Theaters rotate between archetypes (strait, archipelago, mountain pass, urban…); theater #1 is a land-leaning map with a bridged strait (GAMEPLAY §9a, Q-GD-33) |
| Sortie | One unit's life from spawn to RTB or death |
| Package | A formation of up to 4 units with a lead |
| Doctrine | A specialization chosen once per campaign |
| Unit class name | Friendly display name for a unit kind: Striker, Scout, Hauler, Tank, Gunboat, Tanker, Lifter, Sentinel, Spire (Q-NAME-2, working names) |
| Stance | An operator's standing intent for their unit: `press`, `standard`, `cautious`, `guns` (GAMEPLAY §6) |
| Damage state | Healthy → Damaged → Mission-kill → Disabled → Destroyed (GAMEPLAY §6a) |
| Tasking Board | A side's shared queue of jobs. Units without an order take the best open job after the decision window. Both sides have one; the director fills the Static's (GAMEPLAY §1b, Q-GD-34) |
| Job | One task on a Tasking Board (resupply, scout, escort, defend, strike, rescue, repair, assist objective; the Static's board also stages and repositions), with a priority, fitting roles, a slot count and an expiry (GAMEPLAY §1b) |
| Job state | OPEN → CLAIMED → ACTIVE → DONE \| FAILED \| EXPIRED (GAMEPLAY TB-1) |
| Claim lease | How long a unit may hold a claimed job without progress before the job returns to OPEN (TB-1) |
| Decision window | The short hold at base after `!join` before a unit with no order takes a board job (GAMEPLAY §1b). Not the director's decision window (NAMING-CONVENTIONS §3) |
| AUTO unit | A commander's unit that is AI-run after idle handoff, shown with the AUTO tag. It keeps its commander's slot until it retires (GP-4, Q-ALN-9). _Avoid:_ "AI unit", which means an AI-owned entity with the `[AI]` label |
| Idle handoff | After `presence.idle_handoff_min` of game time with no command that reached the sim, the unit finishes its order and becomes an AUTO unit (GP-4, Q-GD-35) |
| Idle retire | After `presence.idle_retire_min` with no such command, the unit RTBs and despawns and its slot frees (GP-5). _Avoid:_ idle despawn (removed, Q-ALN-8) |
| Reclaim | A command from the commander while their AUTO unit lives, which restores their control of that unit; a `!join` reclaims instead of spawning a second unit (GP-6, Q-ALN-9) |
| Reserve queue | Viewers waiting for a unit slot when the cap is reached |
| Rally call | A templated map pin and banner from an O-3+ operator (`!rally`); informs only, never controls other units (Q-SUP-6) |
| World event | A visible, in-fiction event (e.g. supply drop, weather clearing, friendly convoy) from the world-events system or a GM; it may benefit the coalition (Q-AI-8, NX-310) |

## Director, fog of war and readability

| Term | Meaning |
|---|---|
| Pattern of Life (PoL) | The Static's non-aggressive routine (patrols, convoys, rotations, staging) when not provoked; replaces any clock pause (THREAT-DIRECTOR §5a) |
| Provocation | A decaying score that rises with coalition actions against the Static and drives escalation, not headcount (THREAT-DIRECTOR §5a) |
| Threat tier | ALPHA / BRAVO / CHARLIE, the director's escalation level |
| Coalition power (CP) | Smoothed measure of active coalition strength. Drives the tiers |
| Momentum | 0–100% indicator of who's winning, derived from nodes, stock and recent events |
| Theater objective | The system-picked goal shown on screen. Mode per campaign: `timed` (rotating, default 15 min) or `off` (Q-GD-19) |
| SIGINT blob | Fuzzy Tier-1 fog-of-war indication of unseen enemy activity |
| Track / Painted | Tier-2 / Tier-3 fog-of-war states |
| Sitrep | An automated radio situation report |
| HUD tiers | Always on (momentum, objective, threat, how-to-play strip); interrupt toasts (rally calls, mastermind taunts, major alerts); one rotating panel for the rest (Q-UX-11) |
| Spotlight operator | An operator with recent hero events or high recent action, who may be named in taunts more often (THREAT-DIRECTOR TD-4) |

## Time, pauses and operations

| Term | Meaning |
|---|---|
| Tick | One 100 ms simulation step |
| World time | Sim time scaled by `sim.time_scale`; drives movement, logistics, combat, capture and fog-of-war timers (GAMEPLAY timers, Q-ALN-1, Q-ALN-23) |
| Game time | Unscaled sim ticks (1 game minute = 1 real minute while running); drives player-facing durations such as idle handoff, cooldowns, respawn, decision windows and campaign length (Q-ALN-1) |
| Real time | A monotonic clock outside the sim for chat rate limits, digests, taunt, GM, redemption and supply-drop limits; keeps running while the sim is paused (Q-ALN-4) |
| Pause | A sim stop with a reason; it freezes world and game time. Only commands that don't change the world, and staff safety actions, work while paused (Q-ALN-2, Q-ALN-24) |
| Pause category | Why the sim is paused: STAFF (manual, with an optional sub-reason RAID / ABUSE / CONTENT / OTHER), TECHNICAL (offline auto-pause), MAINTENANCE (weekly window) or CEASEFIRE (Q-ALN-3, Q-ALN-31) |
| Offline auto-pause | The TECHNICAL pause after the broadcast is offline longer than `ops.offline_pause_after_min`; resumes after a "COMMS RESTORED" countdown (OPS-ADMIN OA-5, OA-6) |
| Maintenance window | One fixed weekly slot of up to ~2 h; the sim pauses with MAINTENANCE and the stream shows a "back at HH:MM" scene (OPS-ADMIN OA-7, OA-8) |
| Ceasefire mode | The owner's one-click or hotkey pause (CEASEFIRE) for gaming on the broadcast PC: light OBS scene, heavy overlay rendering off (OPS-ADMIN OA-9) |
| Snapshot / Command log | Recovery and replay data (ADR-0003) |
| Reference host | The owner's broadcast host (i7-8700 + GTX 1070 under WSL2) for performance budgets; golden replays use the CI image instead (Q-TEST-1) |
| Harness-validated | A value that met the written balance-harness targets over ≥ 50 seeds and the crowd profiles (0, 5, 50, 150, 300 and 500 simulated viewers plus adversarial profiles), so it can drop its PROPOSED label (Q-TEST-2, Q-ALN-42) |

## Progression and conduct

| Term | Meaning |
|---|---|
| XP | Lifetime experience whose thresholds set a commander's rank; losing a unit never costs XP (PROGRESSION §2–3, GAMEPLAY GP-2). _Not_ Merit |
| Merit | A per-campaign score that resets each war and ranks the overall leaderboard. A score only: never spent or converted (Q-PROG-7, ADR-0011). _Not_ XP |
| Rank id / rank name | Internal ids `O-1`…`O-6`; shown on stream as Recruit, Drone, Specialist, Swarm Lead, Hive Commander, Quorum Marshal (Q-NAME-1, Q-ALN-41; hive ladder, working names). _Avoid:_ Operator, Signal Lead, Wave Commander (retired rank names) |
| AUTO assist | A job completed by a commander's AUTO unit; shown in recaps only and never counts toward XP, Merit or leaderboards (PROGRESSION PROG-12, Q-ALN-30) |
| Held the Line | A cosmetic badge, no XP or Merit, for being the only active Operator for ≥ 30 continuous game-time minutes while the Static is above Pattern of Life (PROG-10, Q-ALN-15, Q-ALN-27). Not the campaign mode below |
| Hold the Line | A campaign mode (P4) that ends after N escalating waves or a time limit (GAMEPLAY §9, Q-GD-15) |
| Season | A leaderboard period of several campaigns (~4–8 weeks); season boards reset, lifetime ranks don't. It ends when the campaign running on its planned end date ends (PROGRESSION §6, Q-UX-2, Q-PROG-9) |
| Season overtime | The time a season runs past its planned end while that campaign finishes, capped by `season.overtime_cap_days` (Q-PROG-9) |
| Conduct standing | Decaying score for clearly disruptive behavior, separate from skill; drives a slow, reversible escalation ladder (ADMIN-RBAC §6.8) |
| Probation tag | Neutral marker on a unit while its operator has an active conduct restriction; no score shown (Q-MOD-6) |

## Content operations

| Term | Meaning |
|---|---|
| Vault | The private repository `operation-nexus-vault`: marketing drafts, production material, lore canon and licensed-asset records. Not the secrets repository (`operation-nexus-ops`). |
| Context pack | A read-only bundle of approved facts and tone (voice summary, `RELEASED` lore, active campaign facts) that services and drafting agents both read. Carries data, never credentials. |
| Content-time agent | An agent that drafts or checks content on a schedule and opens a vault pull request. Distinct from the runtime LLM advisor, which serves the live game. _Avoid:_ "the bot" for either. |
| Draft status | Where a marketing draft stands: `DRAFT`, `APPROVED`, `POSTED` or `REJECTED` (a rejection always carries a reason). |
