## Recommendations

1. **Brand ("Operation Nexus"): move to a more distinctive name before NX-297 creates any accounts.** If the owner keeps it, budget for a professional search in classes 9 and 41 first, and avoid "Operator Nexus" in any copy.
2. **Clearwave: keep it as the in-world faction name.** Don't make it the channel handle or merch brand without checking the official register. If it must be a handle, add a modifier (e.g. "Clearwave Coalition", see below).
3. **The Static: keep it as the enemy faction.** Don't use it alone as a game or channel title. TS-4 already keeps lore names to on-screen labels and sitreps.
4. **NULL: practical risk.** `null`/`NULL` is a literal in JSON, Python (`None` → `null`), TypeScript and SQL. It can make log searches, moderation lists and placeholder checks ambiguous (does "NULL" mean the villain or missing data? That conflicts with DATA-INTEGRITY rule 0). TTS may also read it as "null" or "N-U-L-L". If kept, store it under an internal id (e.g. `enemy_leader`) and render the display string only at the presentation layer. Alternatives below.
5. **Overtone: rename if music credits will show Epidemic Sound or Overtone Studios.** Viewers could take the villain's name for the music label, or the reverse. There is no sign this is infringement, but the confusion is avoidable.
6. **Signal-word caution:** Signal Messenger has taken legal action over "Signal" in a product name ([sdmmag.com](https://www.sdmmag.com/articles/99966-signal-foundation-sues-adt-over-signal-chat-citing-trademark-infringement?v=preview), [signal.org/brand/trademarks](https://signal.org/brand/trademarks/)). Avoid "Signal" as the lead word of a brand.

## Manual steps for owner

Do these for the final brand name first, then the faction names.

- [ ] **USPTO Trademark Search** (tmsearch.uspto.gov): search the exact name, the name without spaces, and each distinctive word alone (e.g. `NEXUS`, `CLEARWAVE`). Open live records in TSDR to confirm status and owner.
- [ ] Classes to filter: **9** (downloadable game software), **41** (entertainment, online game services, streaming shows), **28** (games and toys, relevant for any board/card spin-off), and **25/35** if merch or a store is planned. *Class wording here is a summary; confirm against the official Nice Classification text* **[UNVERIFIED]**.
- [ ] **EUIPO / TMview** (tmdn.org/tmview) and **WIPO Global Brand Database** (branddb.wipo.int): same terms and classes. Add **UKIPO** and **CIPO** if UK/Canada audiences matter.
- [ ] Re-check the specific records cited above (CLEARWAVE reg. 8113483 and UK00908116741; NEXUS ser. 98423446; OVERTONE ser. 99364074 and 79362870) for current status.
- [ ] Stores: search Steam, itch.io, Epic, Xbox, PlayStation, Nintendo eShop, App Store, Google Play and Roblox for the exact name.
